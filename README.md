# OneShell — Samsung One UI (Galaxy Tab S9) look for Windows 10/11

Design mockups for a Windows shell app that makes Windows look and feel like One UI on a Galaxy Tab S9.
Nothing is built yet — these are for discussing the design first.

| # | Screen | Replaces in Windows |
|---|--------|---------------------|
| 1 | ![](mockups/1-lock-screen.png) Lock screen | Windows lock screen |
| 2 | ![](mockups/2-home-screen.png) Home screen with widgets + dock | Desktop + taskbar |
| 3 | ![](mockups/3-quick-panel.png) Quick panel | Action Center / Quick Settings |
| 4 | ![](mockups/4-app-drawer.png) App drawer | Start menu |
| 5 | ![](mockups/5-recent-apps.png) Recent apps | Alt+Tab / Task View |
| 6 | ![](mockups/6-multi-window.png) Split view + pop-up window | Snap layouts |
| 7 | ![](mockups/7-oneshell-settings.png) OneShell settings | — |

The mockups are made from `mockups/mockup.html` (open `mockup.html?s=<screen>`, where `<screen>` is
`lock`, `home`, `quick`, `drawer`, `recents`, `multi` or `settings`).
